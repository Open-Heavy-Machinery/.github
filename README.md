# .github

The organisation-wide repository of [Open Heavy Machinery](https://github.com/Open-Heavy-Machinery).

- [`profile/README.md`](profile/README.md) is the public profile shown on the organisation's GitHub page: mission, how it started, projects, principles and how to get involved.
- `profile/banner-dark.svg` and `profile/banner-light.svg` are the banner for GitHub's dark and light themes. They use the same mark and palette as [the website](https://open-heavy-machinery.github.io): accent `#f0883e` on dark, `#bc4c00` on light (the lighter orange is too faint on white).

The mission, the project list and their statuses must agree with each project's README and with the website. Change them together.
